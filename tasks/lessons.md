# Lessons

## Explain before investigating a side issue

**Correction (2026-09-24):** asked to open the spec with glow "here", I ran
several diagnostic commands (output sizes, hung processes) without saying why,
and the user asked "wait, what are you trying to do".

**Rule:** when a simple request hits a snag, say in one line what went wrong
and what I'm about to check before running diagnostics. If the check isn't
needed to answer the request, answer with what I know and offer the check.
